# Polarity Homebrew tap

Casks for Polarity's command-line tools. GoReleaser publishes them on every release, so don't edit them by hand.

```sh
brew install --cask polarity-dev/tap/mestiere
```

| Cask | Description |
|---|---|
| [mestiere](https://github.com/polarity-dev/mestiere) | Install agent skills from git registries |
